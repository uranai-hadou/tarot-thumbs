# タロットサムネ帳

競合のタロットチャンネルの動画を毎朝6時ごろに自動で集めて、サムネを「普段より伸びた順」に一覧で見るページです。

- ページ: https://uranai-hadou.github.io/tarot-thumbs/
- チャンネルの追加・削除: ページの「チャンネル」タブから（最初に1回だけ鍵の設定が必要）
- 伸び率 = その動画の再生数 ÷ そのチャンネルの普段の再生数（投稿から3日以上たった最新30本の中央値）

## 中身

- `index.html` … ページ本体
- `data/channels.json` … 集めるチャンネルの一覧（ページから書き換わる）
- `data/videos.json` … 集めた動画のデータ（自動で更新）
- `scripts/fetch.py` … データを集める処理。チャンネルページとRSSフィードを読む（APIキー不要）
- `.github/workflows/update.yml` … 毎朝の自動実行と公開
