チャンネル

ここにあるチャンネルの新しい動画を、毎朝6時ごろに自動で集めます。追加すると数分で一覧に並びます。

追加・削除の準備（この端末で1回だけ）

チャンネルを追加・削除するには、GitHubの「鍵」をこの端末に入れておきます。このツール専用の鍵で、ほかのことには使えません。

  1. GitHubにログインした状態で 鍵の作成ページ を開く
  2. Token name に サムネ帳、Expiration は No expiration（なければ一番長い期間）を選ぶ
  3. Repository access で Only select repositories を選び、tarot-thumbs を選ぶ
  4. Permissions の Repository permissions を開き、Contents を Read and write にする
  5. 一番下の Generate token を押し、出てきた github_pat_ で始まる文字をコピーして下に貼る

もう別の端末で設定済みなら、その端末の「ほかの端末に移す」で出るリンクを開くだけで設定できます。

✓ 追加・削除の準備はできています

このリンクをスマホなど自分の端末だけで開いてください。リンクを知っている人はチャンネルを変更できるので、ほかの人には送らないでください。
